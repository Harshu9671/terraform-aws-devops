A hands-on AWS + Terraform project

AWS infrastructure automated with code.

A modular Terraform project that provisions a web server on AWS, stores remote state in S3, and validates infrastructure changes through GitHub Actions.

Terraform · AWS · GitHub Actions

How a change gets deployed

1. Push code

Changes start in GitHub and trigger the workflow.

→

2. Terraform checks it

Format, validate, plan, and review the infrastructure change.

→

3. AWS runs it

The approved configuration becomes real networking and compute.

Tools used

AWSTerraformHCLGitHub ActionsAmazon VPCAmazon EC2Amazon S3Amazon Linux 2023ApacheGitLinux

What is running

Networking

A custom VPC, public subnet, Internet Gateway, route table, and route association.

Web server

An Amazon Linux 2023 EC2 instance installs Apache during first boot and serves this page.

Remote state

Terraform state is encrypted and stored in S3 as a shared source of truth.
